# 動画制作でできることの一覧（Remotion／Runway）

設計判断から動画の制作案を作るとき、Gemini に渡す前提資料。
Gemini はこの一覧にある「場面の種類」だけを使って制作案を組み立てる。ここにないことは提案しない。

- 調査日：2026-10-07（Runway の料金とモデルは変わりやすいので、使う前に公式で確認する）
- 1 クレジット = 0.01 米ドル（Runway API）

## 1. 使い分けの原則

| 判断 | Remotion を使う | Runway を使う |
|---|---|---|
| 作るもの | 文字、図、グラフ、字幕、画面録画の編集、場面の組み立て | 実写風・アニメ風の映像、人物の動き、話す人物 |
| 結果 | 毎回同じ（コードで決まる） | 毎回変わる（生成） |
| 費用 | ほぼかからない（自分の PC で書き出す） | 秒単位で課金 |
| 修正 | 何度でもやり直せる | やり直すたびに課金 |

**原則：Remotion で表現できる場面は Remotion で作る。Runway は「生成でしか作れない映像」に限る。**
最終的な組み立て（場面の連結、字幕、BGM、書き出し）は常に Remotion で行う。

## 2. 場面の種類

制作案は、次の場面の種類を組み合わせて作る。`種類キー` は制作案のデータでそのまま使う。

### Remotion の場面

| 種類キー | 内容 | 必要な素材 | 長さ |
|---|---|---|---|
| `remotion.title` | タイトル・見出し・章扉。文字のアニメーション | 文言 | 自由 |
| `remotion.text` | 箇条書き・説明文を順に表示 | 文言 | 自由 |
| `remotion.diagram` | 図解。四角と矢印、フロー、関係図を順に描く（SVG） | 図の構成（ノードと矢印） | 自由 |
| `remotion.chart` | 棒・折れ線・円グラフが伸びるアニメーション | 数値データ | 自由 |
| `remotion.code` | ソースコードを表示し、行を強調する | コード | 自由 |
| `remotion.image` | 静止画を表示し、ズーム・パン（ケン・バーンズ効果） | 画像 | 自由 |
| `remotion.clip` | 既存の動画（画面録画、YouTube 以外の手持ち動画、Runway の生成物）を切り出して配置 | 動画ファイル | 素材の長さまで |
| `remotion.split` | 画面分割（左右・上下・ピクチャー・イン・ピクチャー） | 動画または画像を 2 つ以上 | 自由 |

全場面に共通して付けられるもの：

- 字幕（台詞やナレーションの文字起こしを時刻に合わせて表示）
- BGM・効果音・ナレーション音声（音量の調整、フェード）
- 場面の切り替え効果（フェード、スライド、ワイプなど）
- 書体（Google Fonts）、配色、ロゴ

### Runway の場面

| 種類キー | 内容 | 入力 | 長さ | 目安の費用 |
|---|---|---|---|---|
| `runway.image_to_video` | 写真やイラストを動かす（顔の向き、表情、カメラの動き） | 画像 1 枚＋動きの指示文 | 5 秒 または 10 秒 | Gen-4 Turbo：0.05 ドル/秒<br>Gen-4.5：0.12 ドル/秒 |
| `runway.text_to_video` | 文章だけから映像を作る | 指示文 | 最大 10 秒（Gen-4.5）<br>最大 30 秒（Seedance 2.5） | Gen-4.5：0.12 ドル/秒<br>Seedance 2.5：0.20 ドル/秒〜 |
| `runway.video_to_video` | 既存の映像を作り替える（画風変更、物の追加・削除、天候や時間帯の変更） | 動画（2〜30 秒、16MB 未満）＋指示文 | 入力と同じ | Aleph 2.0：0.28 ドル/秒 |
| `runway.avatar` | 人物の画像に台詞を話させる（口の動き、視線、頭の動き） | 人物画像 1 枚＋台本または音声 | 台詞の長さ | 0.02 ドル＋0.02 ドル/6 秒 |
| `runway.image` | 場面の素材となる静止画を作る | 指示文（参考画像も可） | － | Gen-4 Image Turbo：0.02 ドル/枚 |
| `runway.speech` | 台本からナレーション音声を作る | 台本（2,500 文字まで） | 台本の長さ | Eleven v4：0.022 ドル/1,000 文字〜 |
| `runway.sound` | 効果音・環境音を作る | 指示文 | 自由 | Seed Audio：0.0025 ドル/秒 |

`runway.image` と `runway.sound` は再生される場面ではなく、他の場面が使う素材（material）として作る。`runway.speech` は場面にせず、各場面のナレーションの文言から自動で作る。詳しくは scene_content.md。

比率は横 1280:720、縦 720:1280、正方形 960:960 などから選ぶ。入力画像が比率と合わないときは、中央で切り取られる。

## 3. 組み合わせの例

| 目的 | 組み立て |
|---|---|
| 設計判断の解説動画 | `remotion.title` → `remotion.diagram` → `remotion.text` → `runway.speech` でナレーション |
| 写真の人物があいさつする | `runway.avatar` → `remotion.clip` で配置し、字幕と BGM を付ける |
| 写真から短い印象的な映像 | `runway.image_to_video`（5 秒）→ `remotion.clip`＋`remotion.title` |
| 操作手順の説明 | 画面録画を `remotion.clip` で切り出し → `remotion.text` で手順番号を重ねる |
| 実写風の導入 | `runway.text_to_video`（5 秒）→ `remotion.title` を重ねる |

## 4. できないこと・注意すること

| 項目 | 内容 |
|---|---|
| 1 場面の長さ | Runway の生成は 1 回 5〜10 秒が基本（Seedance 2.5 は最大 30 秒）。長い映像は場面を分けて Remotion でつなぐ |
| 同じ人物・同じ物の一貫性 | 生成のたびに見た目が変わる。同じ人物を続けて出すときは、同じ参考画像から `runway.image_to_video` を使う |
| 生成映像の中の文字 | Runway は文字を正確に描けない。文字は必ず Remotion で重ねる |
| 音声 | Runway の映像生成は音を付けない前提で考える。音は `runway.speech`／`runway.sound` または手持ちの音源を Remotion で合わせる |
| 実在の人物 | 本人の同意がない人物の顔や声は使わない |
| YouTube の動画 | 分析元の YouTube 動画を素材として切り出して使わない（権利の問題） |
| 費用 | Runway の場面は、人が制作案を採用してから生成する。Remotion の場面は静止画（モック）で確認してから書き出す |
| Remotion のライセンス | 個人または 3 人以下の会社は無料。それ以上の会社は有料ライセンスが必要 |

## 5. 確認が必要なこと

- Runway の各モデルで選べる長さと比率の正確な一覧（公式の API リファレンスで確認する）
- Runway API キーの用意（`.env` に `RUNWAYML_API_SECRET` を追加する）
- Remotion のプロジェクトの置き場所（このリポジトリ内か、別のリポジトリか）
